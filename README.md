# AI 加词 · uTools

在 uTools 8.0 或更新版本中连接自己的加词服务，学习当前词库。主界面与悬浮小窗共用一份词卡队列，评分和 AI 生成沿用服务端的进度与额度。

## 构建和导入

在 `jiaci-utools` 目录使用 Node.js 22.12 或更新的 LTS 版本运行：

```sh
npm ci
npm run build
```

1. 在 **uTools 开发者工具 → 开发 → 导入源码工程** 选择本目录的 `plugin.json`，然后点击 **安装（开发模式）**。已有开发项目可保留原导入位置，构建后重新加载插件。
2. 点击 **打开**，或在 uTools 中搜索 `AI加词`。填写加词站点地址，选择站点启用的登录方式。邮箱登录需先获取验证码，密钥登录使用站点管理员分配的密钥。
3. 用工具栏左侧的按钮收起或展开词库侧栏。窄窗口中，按钮打开词库抽屉。默认显示 **正在学习** 和 **我的词库**，可切到 **其他词库** 浏览内置词库。点词库名称可按学习状态筛选、搜索和翻页，点单词可查看详情。用 **设为当前学习** 切换队列。
4. 在 **设置 → 学习计划** 修改每天的新词量、复习上限与学习顺序。**设置 → 发音** 可调整口音、声音、例句喇叭位置与自动朗读。保存后与 Web 端共用这些账户设置。**插件内发音** 是本机总开关。

`dist/plugin.json` 是独立构建的导入入口，可用于分发或打包。修改界面后重新运行 `npm run build`。

[uTools 开发者工具说明](https://www.u-tools.cn/docs/getting-started/create-plugin.html)

## 小窗和老板键

1. 登录后通过右上角的小窗图标，或 **设置 → 通用 → 显示小窗**，打开和隐藏小窗。显示开关会同步反映工具栏、小窗和老板键的操作。
2. 打开 **设置 → 快捷键**，点击 **老板键** 所在行的全局设置。在 uTools 给 **加词老板键** 绑定一个按键，例如 `Ctrl+Alt+J`。
3. 切到其他程序，按一次老板键隐藏，按第二次回到刚才的词卡。
4. 在 **设置 → 通用 → 学习小窗** 调整 **始终置顶** 和 **整体缩放**。置顶默认开启，可随时切换。缩放范围为 60%–200%，窗口、文字和控件一起变化。宽度和高度以 100% 为基准，窗口大小受屏幕可用区域限制。
5. 主界面和小窗各自保存明暗模式。小窗的背景颜色按模式保存，不透明度作用于整个小窗。拖动标题栏可移动小窗，开启 **背景完全透明** 时改为拖动顶部短横。开启 **插件内发音** 后可播放单词和例句。

uTools 管理插件的后台运行时间。长时间使用小窗时，可在 uTools 中关闭该插件的 **退出到后台立即结束运行**，并检查后台结束时间设置。宿主结束插件后，老板键能重建小窗，并在今日队列中恢复仍待学习的那张卡。

[uTools 自定义窗口](https://www.u-tools.cn/docs/development/custom-window.html) · [uTools 全局快捷键](https://www.u-tools.cn/docs/api-reference/redirect.html)

## 学习快捷键

| 默认窗口内按键 | 操作 |
| --- | --- |
| `Enter` | 显示答案 |
| `1` / `2` / `3` / `4` | 在答案页标记认识 / 模糊 / 已掌握 / 重新记 |
| `5` | 生成 AI 资料，已有资料时重新解析 |
| `D` | 展开或收起关联词、助记、短语、例句等词条资料 |
| `Space` | 发音，需开启插件内发音 |

主界面和小窗都会在学习操作旁显示已配置的窗口内按键。**设置 → 快捷键** 可以录制窗口内按键，也可在 **全局** 列给单项学习操作绑定 uTools 快捷键。全局学习操作在小窗显示时生效。

显示答案后，点击词卡里的 **刷新词条** 可读取最新资料。AI 生成完成后也会自动刷新当前词条。

小窗偏好、最近的词卡位置和登录会话保存在 uTools 的插件本地数据目录。退出登录会清除本地会话。
